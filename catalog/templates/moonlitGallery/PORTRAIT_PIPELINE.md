# 前景立绘管线（1bpp）

这套流程适用于所有前景角色，不依赖某一张图或某一部作品。

1. 准备完整角色 PNG：角色四周留白、无场景、无投影；透明源图会先铺为纸白。剧情舞台默认用半身/胸像构图；若源图是全身图，在编码时显式提供 `portraitFrame`，不要把整个人缩进一个角色槽位。
2. 把背景图和角色**细节层**统一以 Floyd–Steinberg **50%** 强度转为 1bpp。人物可使用更高的保细线阈值，保证脸部线稿不会在缩放后消失。
3. 角色额外生成实心 `char_*_matte`。背景不是“所有白色”，而是“从图像四边能连通到的纸白”；被线稿围住的白脸、白衬衫和高光都属于前景。
4. 在 XTApp Studio 中重新生成素材并检查预览。
5. 在实际预览中检查单人、双人和三人场景：脸部/衣物不能透出背景，角色边缘不能露出原图背景。

不要给 matte 抖色。它是纯覆盖层；先以 `color = 0` 画出纸白人物轮廓，再叠加 50% 抖色的细节层。
